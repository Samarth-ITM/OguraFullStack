# Ogura Seedling

Build the simplest possible static website: one minimal page with a clean hero (site title "Ogura", a one-line placeholder tagline, and a simple "Coming soon" section). No backend, no database, no auth, no extra pages, no extra features. Keep it to a single small page.

This project was built with [Lovable](https://lovable.dev).
